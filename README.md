# Perfect Tax.co Landing Page

A completely static, responsive tax-services landing page built with semantic HTML, Bootstrap 5, modular SCSS, and a small amount of vanilla JavaScript.

## Preview

Open `index.html` directly in a browser. The compiled CSS, Bootstrap bundle, JavaScript, and logo are included locally, so the page does not require a backend.

## SCSS development

```bash
npm install
npm run dev
```

Create the production stylesheet with:

```bash
npm run build
```

All buttons and links are intentional visual placeholders. No form submission, authentication, payments, API calls, WhatsApp integration, or backend behavior is implemented.
